PICCOLO LINGUAGGIO, GRANDI CONNESSIONI

La sintassi, in breve.

UML4ALL ha una propria sintassi: non interpreta il codice PlantUML. Una dichiarazione per riga; parentesi graffe su righe dedicate, salvo l’apertura di diagrammi, gruppi ed elementi.

diagram "Il mio schema" {
  direction right
  zone "Applicazioni" {
    server app "API" {
      ip = "10.0.1.10"
      note = "Servizio principale"
    }
    database db "Archivio"
  }
  app -> db : SQL
}

Elementi disponibili

cloud, router, firewall, switch, network, server, database, service, actor, task, decision, start, end, node.

Gruppi, collegamenti e dettagli

  • zone "Nome" { e group "Nome" { creano gruppi annidati.
  • a -> b -> c collega una sequenza. a <-> b è bidirezionale; a -- b non ha frecce; a --> b è tratteggiato.
  • a -> b : Etichetta aggiunge una descrizione al collegamento.
  • direction right oppure direction down sceglie l’orientamento per tutto il diagramma.
  • Proprietà dentro un elemento: ip, subnet, vlan, protocol, owner, note, color (es. "#dbeafe").
  • Identificatori: lettere, numeri, trattino e underscore; primo carattere una lettera o underscore. Etichette fra virgolette; \n per andare a capo.
  • Commenti su una riga con // oppure #. I riferimenti possono precedere le dichiarazioni.

Prototipo 0.1: layout automatico di base. Nei grafi molto densi alcuni collegamenti possono incrociarsi. Fino a 250 elementi e 500 collegamenti.
